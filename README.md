# SES Privacy Policy (Google Play landing)

React + Vite + Tailwind CSS landing page and privacy policy for **Power Customer Portal** (SES Smart ElectriCare).

## Run locally

```bash
cd ses_privacy_policy
npm install
npm run dev
```

## Build for hosting

```bash
npm run build
```

Deploy the `dist/` folder to any static host (Netlify, Vercel, GitHub Pages, nginx, etc.). Use the public HTTPS URL as the Google Play **Privacy Policy** link.
